# AI Agent Instructions

These instructions apply to Antigravity, Opencode, and any other AI coding assistant operating in this repository.

Before making any changes to the NixVim configuration or adding new plugins, you MUST check the documentation for NixVim directly or the documentation of the specific plugin in use.

You can check Nixvim documentation through:
1. Online repository: https://github.com/nix-community/nixvim/tree/main 
2. The specific documentation for the plugin in use.

**Important Rule:** Do NOT make your own custom implementations for features if a built-in component or standard configuration option provided by NixVim or the plugin already exists. Always leverage built-in functionality over custom boilerplate.
